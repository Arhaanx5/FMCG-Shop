# WebLogic Server Monitoring & WhatsApp Bot

यह एक लाइटवेट और इंटेलिजेंट ऑटोमेशन स्क्रिप्ट है जो आपके **Oracle WebLogic Console** को 24/7 लाइव मॉनिटर करेगी और किसी भी गड़बड़ी पर तुरंत आपके **WhatsApp Group** पर अलर्ट और स्क्रीनशॉट भेज देगी।

---

## Features (मुख्य विशेषताएं)

1. **Live Continuous Monitoring:** यह स्क्रिप्ट बैकग्राउंड में 24/7 चलती है। यह लॉगिन करने के बाद केवल **एक बार 🔄 (Auto-Refresh Circle)** बटन पर क्लिक करके कंसोल के इन-बिल्ट लाइव मोड को चालू कर देती है।
2. **Intelligent Alerting:** अगर कोई नोड वार्निंग/क्रिटिकल में जाता है या सॉकेट्स की संख्या 20 से ऊपर होती है, तो स्क्रिप्ट **5 मिनट** वेट करती है, रिफ्रेश करके दोबारा चेक करती है, और समस्या बने रहने पर ही अलर्ट भेजती है।
3. **Console Stale Check (Time Sync Check):** स्क्रिप्ट लाइव कंसोल टाइम (जैसे: `as of 6:36 PM`) को सिस्टम टाइम से मैच करती है। यदि अंतर **10 मिनट से अधिक** होता है, तो यह तुरंत व्हाट्सएप पर अलर्ट भेजती है कि कंसोल पेज हैँग या फ़्रीज़ हो गया है।
4. **Routine Hourly Reports:** हर 1 घंटे पर ऑटोमैटिकली पूरे सर्वर टेबल का स्क्रीनशॉट और हेल्थ समरी व्हाट्सएप ग्रुप में चली जाती है।
5. **Persistent Context:** व्हाट्सएप वेब का QR कोड सिर्फ **एक बार (Only Once)** स्कैन करना होगा। उसके बाद सत्र हमेशा सेव रहेगा।

## Installation & Setup (सेटअप कैसे करें)

### Step 1: Python और Libraries इंस्टॉल करें
1. सुनिश्चित करें कि आपके सिस्टम पर **Python 3.8+** इंस्टॉल है।
2. अपने टर्मिनल/कमांड प्रॉम्प्ट (CMD) में `weblogic-monitor` फोल्डर के अंदर जाएँ और निम्न कमांड्स चलाएँ:
   ```bash
   pip install -r requirements.txt
   ```
3. Playwright ब्राउज़र को इंस्टॉल करने के लिए यह कमांड चलाएँ:
   ```bash
   playwright install chromium
   ```

### Step 2: Configuration सेट करें (`config.json`)
[config.json](file:///d:/intelliJ2025/fmcg-shop/fmcg-shop/weblogic-monitor/config.json) फ़ाइल खोलें और अपनी आवश्यकतानुसार वैल्यूज़ अपडेट करें:
* `weblogic_url`: आपके वेबलॉजिक एडमिन कंसोल का IP और पोर्ट।
* `weblogic_user`: वेबलॉजिक का यूज़रनेम।
* `weblogic_password`: वेबलॉजिक का पासवर्ड।
* `whatsapp_group_name`: आपके व्हाट्सएप ग्रुप का **बिल्कुल सटीक नाम** (Case Sensitive)।
* `socket_threshold`: जितने सॉकेट के बाद आप अलर्ट चाहते हैं (डिफ़ॉल्ट `20`)।

## How to Run & Verify (कैसे चलाएं और टेस्ट करें)

### 1. One-Time WhatsApp QR Setup (व्हाट्सएप लॉगिन करना)
व्हाट्सएप सेशन को पहली बार रजिस्टर करने के लिए यह कमांड चलाएँ:
```bash
python monitor.py --setup
```
* एक ब्राउज़र खुलेगा जिसमें **WhatsApp Web** लोड होगा।
* अपने फोन से QR कोड स्कैन करें और पूरी तरह लॉगिन होने दें।
* लॉगिन होने के बाद, कमांड प्रॉम्प्ट पर वापस आकर **[Enter]** दबाएँ। आपका सेशन हमेशा के लिए सेव हो जाएगा!

### 2. Run in Dry-Run Mode (सुरक्षित लाइव टेस्ट)
यह कमांड बिना व्हाट्सएप पर मैसेज भेजे वेबलॉजिक लॉगिन, 🔄 ऑटो-रिफ्रेश क्लिक, लाइव सर्वर स्टेटस रीडिंग, और टाइम-सिंक को विज़ुअली टेस्ट करेगी:
```bash
python monitor.py --dry-run
```
* **क्या चेक करें:** ब्राउज़र ओपन होगा, वेबलॉजिक लॉगिन करेगा, 🔄 बटन दबाएगा और कमांड प्रॉम्प्ट पर आपको सभी सर्वर्स का स्टेट और टाइम डिफरेंस प्रिंट करके दिखाएगा।

### 3. Run Live 24/7 (लाइव मॉनिटरिंग चालू करें)
सब कुछ वेरीफाई होने के बाद, लाइव बैकग्राउंड मॉनिटरिंग शुरू करने के लिए यह कमांड चलाएँ:
```bash
python monitor.py
```
* यह बैकग्राउंड में बिना स्क्रीन को डिस्टर्ब किए (Headless mode) शांति से चलती रहेगी और लाइव काम करेगी।
* आप चाहें तो इसे बंद होने से बचाने के लिए विंडोज के स्टार्ट-अप स्क्रिप्ट में भी जोड़ सकते हैं।
